# Taste

为自己做的音乐与播客播放器。一个纯前端 PWA，部署在 GitHub Pages 上，所有数据保存在设备本机。

## 功能

- **本地音乐**：导入手机或电脑里的 MP3 / FLAC / M4A / WAV 等文件，自动读取歌名、歌手和封面；歌曲保存在浏览器本机存储中，离线可播
- **播客**：按名称搜索（Apple Podcasts 目录）或粘贴 RSS 链接订阅；每集收听进度自动记忆，支持倍速、±15/30 秒跳转
- **驾驶模式**：全黑大按钮界面、屏幕常亮，配合蓝牙连接车机后可用方向盘按键控制
- **锁屏控制**：锁屏界面和蓝牙设备上显示曲目信息与控制按钮（Media Session）
- **沉浸式界面**：环境光随专辑封面变化，深色 / 浅色主题

## 安装到手机

1. 用手机浏览器打开本应用网址
2. **iPhone**：Safari → 分享按钮 → 「添加到主屏幕」
3. **安卓**：Chrome → 右上角菜单 → 「安装应用」

之后从主屏幕图标打开，就是全屏独立应用。

## 隐私

没有服务器、没有账号。音乐文件、播客订阅与收听进度全部存储在你自己设备的浏览器里（IndexedDB），不上传任何数据。播客搜索与节目源抓取直接请求 Apple 目录和节目方的 RSS（个别源通过公共 CORS 代理中转）。

## 开发

纯静态页面，无构建步骤。本地预览：

```bash
python3 -m http.server 8080
```

推送到 `main` 分支后由 GitHub Actions 自动部署到 GitHub Pages。
